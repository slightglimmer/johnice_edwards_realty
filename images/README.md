# Site photos

Drop photos into this folder using **exactly** these file names (lowercase, `.jpg`).
Until a file is added, the site shows a soft colored placeholder with its photo number.
If you upload a `.png` or `.webp` instead, the file name in the HTML pages has to change too.

Sizes are width × height in pixels. Bigger is fine if the shape matches; keep files
under about 400 KB each (squoosh.app or tinypng.com can shrink them) so pages load fast.

## Uploading on GitHub

1. Open this `images` folder on GitHub.
2. Click **Add file → Upload files** and drag your photos in.
3. Click **Commit changes**.
